Detailed Description

Bit positions within SW_INT_STAT0 (Reg 0x08) — low-side current-limit faults.

Data sheet Table 90. STAT bits are RW1C: read 1 = event latched, write 1 to clear. The corresponding SW_INT_SENSE0 (0x0A) shows the instantaneous (live) state with the same layout.
