Register map¶

The PF1550 registers the driver names in pf1550::Register, with their data-sheet names, and the interrupt bit layout the fault reader depends on.

Addresses are absolute: the PMIC page is 0x00 to 0x7F and the charger page starts at 0x80 (kChargerPageBase), so the data sheet's charger register CHG_SNS, offset 0x07, is 0x87 here. Table numbers refer to the PF1550 data sheet, Rev. 7, section 12. Any register can be read or written with ReadRegister() / WriteRegister().

Interrupt registers¶

Each interrupt source has three registers: STAT (latched, write 1 to clear), MASK (1 = masked, the reset value) and SENSE (the live state). INT_CATEGORY (0x06) has one bit per group and is the cheap first read.

Register Bits, from bit 0 Meaning
INT_CATEGORY (0x06) CHG_INT, SW1_INT, SW2_INT, SW3_INT, LDO_INT, ONKEY_INT, TEMP_INT, MISC_INT A group has a pending interrupt
SW_INT_STAT0 (0x08) SW1_LS_I, SW2_LS_I, SW3_LS_I Low-side current limit
SW_INT_STAT1 (0x0B) SW1_HS_I, SW2_HS_I, SW3_HS_I High-side current limit
SW_INT_STAT2 (0x0E) SW1_DVS_DONE_I, SW2_DVS_DONE_I DVS transition finished
LDO_INT_STAT0 (0x18) LDO1_FAULTI, LDO2_FAULTI, LDO3_FAULTI LDO fault
TEMP_INT_STAT0 (0x20) THERM110I, unused, THERM125I Die temperature crossed 110 °C / 125 °C
MISC_INT_STAT0 (0x28) PWRUP_I, PWRDN_I, PWRON_I, LOW_SYS_WARN_I, SYS_OVLO_I Back in RUN, entered STANDBY / SLEEP, PWRON button, VSYS below LOW_SYS_WARN, VSYS over SYS_OVLO

ReadLatchedFaults() maps these bits into FaultFlags: SW1/2/3_LS_I and _HS_I to kSwNLs / kSwNHs, LDOn_FAULTI to kLdoNFault, THERM110I to kTempWarn, THERM125I to kTempShdn, PWRON_I to kPwrOn, LOW_SYS_WARN_I to kVsysLow and SYS_OVLO_I to kVsysOv. PWRUP_I and PWRDN_I are mode-transition events and are not mapped. The SENSE registers use the same layout as their STAT registers.
