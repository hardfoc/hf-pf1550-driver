Detailed Description

template<typename BusType>
class pf1550::PF1550< BusType >

CRTP-based PF1550 PMIC driver.

Template Parameters
BusTypePlatform bus type inheriting from pf1550::BusInterface<BusType>. Must implement Write(addr, reg, data, len), Read(addr, reg, data, len), EnsureInitialized(), GpioSet(CtrlPin, GpioSignal), and DelayUs(uint32_t).
Thread-safety
The driver itself is not thread-safe by design — it expects the BusType adapter (or a host mutex wrapping it) to enforce single-writer access. Concurrent reads from another core are tolerated provided the bus adapter serialises I²C transactions.
Single-point-of-failure mitigation
See pf1550::FaultSeverityPortentaH7 — that mapping is the Portenta H7 MCU-on-SW3 eval tree. Other hosts supply their own severity table.

noexcept

Apply the Portenta-H7-on-carrier profile.

Differences from the default:

  1. SW1 (+3V1SW) sequenced first — feeds LDO inputs on Portenta.
  2. SW2_CTRL = 0x0F — full enable including STANDBY (carrier +3V3 stable).
  3. Charger LED disabled to suppress orange CHGB blips.

Apply an arbitrary profile (sequence of register writes).

The profile is applied in order, observing each entry's delay_us setting. Used for the Portenta H7 default and carrier variants below, and for board-specific profiles in downstream projects.

Note
PF1550 state survives MCU reset — voltage changes typically require a full power cycle to take effect. Soft reset alone is insufficient.

◆ RefreshStatusSnapshot()

template<typename BusType >
bool pf1550::PF1550< BusType >::RefreshStatusSnapshot ( DiagnosticSnapshot & snap)
noexcept

Refresh only the status part of a snapshot (≈14 register reads).

Re-reads what can change without a register write: INT_CATEGORY, STATE_INFO, charger and VBUS sense, and the latched + live fault registers (with the per-rail fault marks). Identity, rail set points and enables and the VBUS input limit are kept from the last ReadDiagnosticSnapshot into snap — a monitor polling at 20 Hz does a full read now and then (say once a second) to catch a configuration change, and the status in between at half the bus time.

Parameters
[in,out]snapSnapshot from a previous full read.
Returns
true when every status read succeeded (sets read_ok).

bool enabled )
inlinenoexcept

Declare the SW1 / SW2 voltage encoding the part's OTP selects.

OTP_SWx_DVS_SEL decides between two tables (datasheet Table 31): DVS enabled 0.6–1.3875 V in 12.5 mV steps, DVS disabled an 8-point table up to 3.3 V. It lives in OTP (indirect access only), so the board declares it; the default is disabled (Portenta H7: SW1 3.0 V / SW2 3.3 V exist only in that table).

Parameters
sw_index1 or 2.
