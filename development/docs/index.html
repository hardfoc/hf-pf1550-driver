HF-PF1550 documentation

Welcome. This site mirrors the docs/ folder and documents the NXP PF1550 PMIC family driver used on Portenta H7 and Synapse MCU power domains.

Browse on GitHub: repository home · Issues

Documentation structure

Getting started

  • Installation — Toolchain, CMake, generated headers
  • Quick start — Minimal I2C bus adapter + device probe
  • Chip reference — Parts, DEVICE_ID, family scope

Hardware & integration

  • Hardware setup — ESP32-C6 — Lab I2C wiring for examples
  • ESP32-C6 provisioning — External I2C PMIC setup before MCU bring-up
  • Portenta H7 profile — Default + carrier profiles, rails, straps
  • Configuration — Profiles, per-rail tuning, interrupt masks
  • CMake integration — hf::pf1550, build settings
  • Platform integration — hf-core Pf1550Handler

Reference & examples

  • API reference — PF1550<BusType>, diagnostics, errors
  • Examples — ESP32-C6 probe, diagnostics, provisioning
  • Troubleshooting — OTP locks, I2C, power-cycle behavior

Manufacturer

  • Datasheet & links — PDF fetch, readable extracts

Recommended reading order

  1. Installation
  2. Chip reference — confirm 0x7C @ 0x08
  3. Quick start — implement BusInterface
  4. Portenta profile — if targeting Portenta / Synapse
  5. Examples — ESP32-C6 CI-safe probe

Verification (software-only)

Run the scaffold verifier before opening a PR:

1

./scripts/verify_driver_scaffold.sh

Hardware validation (scope, rail voltages, USB bring-up) remains a human operator step.
